# 区間セルプレイヤー（試作）

[English](README.en.md)

動画・音声に「目印（点）」と「セル（範囲）」を付けて、3段階いいね・コメント・ブックマーク・リピートで学習や鑑賞に使うプレイヤーです。
シャドーイング・ディクテーション・単語帳など、字幕や文字起こしを使った学習もできます。

- ファイルはブラウザの中だけで再生し、どこにも送信しません。メモもブラウザの中に保存されます（[プライバシーとデータの扱い](privacy.html)）
- サーバー側の処理はなく、HTML・CSS・JavaScript だけで動きます（ビルド不要）
- PC の Chrome（または Edge）向けです。音声認識は Chrome で使えます
- 画面は日本語と英語に対応しています。ブラウザの言語が日本語以外なら英語で表示し、「設定」や最初の画面の「English」で切り替えられます（`?lang=en` を付けた URL でも英語になります）

## 起動のしかた

### Web で使う

**https://pe-kun333.github.io/cells-player/** を Chrome で開くだけで使えます。
アドレスバー右のインストールのアイコン（または「?」の画面の「アプリとしてインストール」）で PC にアプリとして入れると、
専用のウィンドウで開き、オフラインでも起動できます。インストールしたあとは、動画や字幕のファイルを右クリックの「プログラムから開く」で直接開けます。

### 手元の PC で使う

1. `start.bat` をダブルクリックします（Python が必要です）
2. Chrome で `http://127.0.0.1:8765/` が開きます（Chrome がないときは既定のブラウザで開きます）
3. 動画・音声ファイルを画面にドロップするか、「ファイルを開く」を押します
   YouTube の URL を入力して「開く」でも使えます（軽量モード）

終わるときは、黒いウィンドウを閉じてください。

> `index.html` を直接ダブルクリックしても動きません。`start.bat` から起動してください。

## 基本の流れ

1. 見ながら `M` キーで目印を付ける（再生は止まりません）
   「−3秒」などのボタンで、少し前に付けることもできます
2. 目印を付けた直後に `1` `2` `3` でいいね、`C` でコメント
   `C`（コメントマーク）を押した瞬間に位置が固定されるので、書くのに時間がかかってもずれません
   （固定した位置は ±1 秒で調整でき、Esc で取り消すと何も残りません）
   よく使うコメント（「要復習」「名場面」など）は `4`〜`9` で1回押すだけで付けられます
   鉛筆ボタンで内容を編集でき、学習用・鑑賞用などのセットを切り替えられます
   名前を変えると、それ以降は別のタグとして記録されます（右のサイドバーでタグごとに絞り込めます）
3. タイムラインの「区間」をクリックすると、目印と目印の間がセルになります
   ドラッグすると複数の区間をまとめたセルになります（セル同士の重なりも可）
4. 右のサイドバーでセルに評価・メモ・コメントを付け、リピート再生します
   字幕・文字起こし（.srt / .vtt / Whisper や cellview の JSON）は、再生ボタンの並びの「字幕」か、画面へのドロップで読み込めます
   動画の下のほうに字幕が出て（T キーか「字幕」ボタンで表示の切り替え）、セルの「文字起こし」でその区間の文字を読めます
   「設定」の「動画の上に字幕を表示する」を外すと、読み込みや音声認識をしても動画の上には出ません
   YouTube の「文字起こしを表示」の一覧をコピーして、「貼り付け」ボタンか Ctrl+V で貼り付けても読み込めます
   「音声認識」ボタンで、流れている音声を Chrome の音声認識でその場で文字起こしできます（行は右下の「文字起こし」に並びます）
   （PC の音を「ステレオ ミキサー」などでマイクとして入力する設定が必要。音声は Google に送られます）
   メモはクリックでその場で編集でき、Enter で改行、Ctrl+Enter か外をクリックで保存されます
   上の検索欄と並び順（時間順・いいね順・作った順・コメント順）で一覧を探せます
   「一覧を連続再生」で、いま一覧に並んでいるセル・目印を上から順に続けて再生できます（ダイジェスト）
   絞り込み・検索・並び順がそのまま使われます。目印は少し前から数秒あとまでを再生します（秒数は設定で変更）
   セルのチェックボックスで複数選ぶと「連結」で1つのセルにまとめられます（タイムラインでは Ctrl+クリックでも選べます）
   定型コメントを付けた目印は、アイコンにそのキー番号（4〜9）が出ます
   時間の横の「−3秒」ボタンで、その少し前へ移動できます（秒数は設定で変えられます）
   時間ボタン・「−3秒」・「ここに移動」などは、1回押すと移動だけ、すばやく2回押すと移動して再生を始めます
   サイドバーの下には「瞬間のコメント」が時間順に小さく並びます
   「連動」では再生位置に合わせて自動でスクロールし、「連動しない」では自由にスクロールできます

## 文字起こしを使った学習

右下の「文字起こし」タブで、字幕・文字起こしの行を使えます。

- 行をクリック → 「移動」「3秒前から」「コメント」のほか、「編集」（Enter で保存・Shift+Enter で改行・Esc でやめる）、「単語帳」、削除ができます（Ctrl+Z で元に戻せます）
- 1行目をクリックしてから別の行を Shift+クリック → 選んだ範囲を「セルにする」
- 「シャドーイング」: 1行ずつ再生して止まるので、そのあいだに声に出します（待ち時間・くり返し回数・文字を見せるかを選べます）
- 「ディクテーション」: 字幕を隠して1行ずつ再生し、聞こえたとおりに入力して Enter で答え合わせ（違う所に印が付き、一致率が出ます。Shift+Enter でもう一度聞く）
- 「ツール」: .srt / .vtt / テキストで書き出し、字幕の時刻のずれを ±0.1 秒・±1 秒で直す、すき間や長さで自動的にセルに分ける
- 単語帳: 行の中の言葉をドラッグで選んで「単語帳」（または W キー）で、前後の文・時刻と一緒に保存します
  上の「単語帳」から一覧を見て、その場面へ戻ったり、CSV（Anki・Excel 向け）で書き出したりできます

セルのリピートは、サイドバー上部の帯で回数（ずっと・2〜20回）、ループの間の無音（1〜5秒）、「だんだん速く」（0.7倍から1回ごとに速く）を選べます。

キー操作の一覧は、画面右上の「?」から見られます。

## 共有リンク（X などで共有する）

YouTube の動画（とネット上の動画）なら、セル・コメントを入れたリンクを作って、ほかの人と共有できます。

- 上の「共有」で、表示名・含めるもの（セルとメモ・目印・コメント・定型コメント・いいね）・範囲・見る人が始める位置を選び、「リンクをコピー」か「X に投稿」を押します（X では投稿画面が開くだけで、投稿するのはあなたです）
- リンクを開いた人のところでは、同じ動画が YouTube から再生され、あなたのセル・コメントが「〇〇さんの共有」として色付きで並びます。その人の自分のメモとは混ざりません
- 共有されたものは見る・移動する・リピートするだけで、編集はできません。いいねやコメントは、その時刻の自分の目印に付きます
- サイドバー上部の「共有されたメモ」で、人ごとに表示・非表示を切り替えたり、「取り込む」で自分のメモにしたり、「外す」で消したりできます（Ctrl+Z で戻せます）
- メモはリンク（アドレスの # より後ろ）に入るので、サーバーは使いません。リンクはその時点の写しなので、あとでメモを足したら作り直してください
- 手元のファイルは、見る人が同じファイルを持っていないので共有できません

## YouTube のライブ配信

ライブ配信の URL（`…/watch?v=…` か `…/live/…`）を開くと、見ながら目印・セル・コメントを付けられます。

- 時刻の横の「ライブ」ボタンに、最新の場面からどれだけ遅れているかが出ます。押すと最新の場面に戻ります
- ライブ配信のあいだは、画面の左に YouTube のライブチャットが出ます（YouTube が用意しているチャットの埋め込み）。このブラウザで YouTube にログインしていれば、そのまま自分のアカウントで書き込めます
  「チャット」ボタンや「設定」で表示しないようにもできます。ここに出ないときや書き込めないときは「別ウィンドウ」で YouTube のチャットを開けます
- チャットの下の帯で、チャットと X に書けます
  - 配信のハッシュタグを登録できます（動画ごとに覚えます）。「X で見る」で、そのハッシュタグの X の最新の投稿を、画面の左端に縦長の別ウィンドウで開きます（X の画面はアプリの中には埋め込めません）
  - 書く欄に書いて、送り先のボタンを押します。書いた内容は、書き始めた時刻の瞬間のコメントとしてアプリにも残り、送った先の印（YT・X）が付きます。Enter は、最後に使った送り先で送ります
    - 「チャット用にコピー」: 文をコピーします（チャットには自動では送られません）。左のチャットの入力欄をクリックして Ctrl+V → Enter で送ります（埋め込んだ YouTube のチャットには、ブラウザの安全の仕組みでアプリから直接書き込めないため）
    - 「X へ」: 書いた内容とハッシュタグを入れた X の投稿画面を、小さな別ウィンドウで開きます（投稿するのはあなたです）
    - 「両方」: その両方を一度に行います
  - 「リンク」をオンにすると、X へ送るときにその時刻の動画へのリンクも付きます（アーカイブになったあとは、その場面から見られます）
- ライブ中に付けたものは、配信が終わってアーカイブになったあとも、同じ URL を開けばそのまま使えます
- アーカイブで冒頭や途中がカットされていると、時刻がずれることがあります。そのときは、アーカイブを開いたときに出る「ライブ中に付けた記録をアーカイブに合わせる」で合わせます
  1. ライブ中に付けた目印をクリックして選ぶ
  2. アーカイブでその場面まで移動する
  3. 「すべて合わせる」を押す（途中がカットされていたときは、カットの後ろの目印で「ここから後ろだけ」）
- あとから直したいときは、再生ボタンの並びの「ライブの記録を合わせる」から開けます（Ctrl+Z で元に戻せます）
- チャンネルの「ライブ」ページの URL では開けません。配信の画面を開いて、その URL を貼ってください。埋め込み再生が許可されていない配信は見られません

## データの保存について

- メモ（目印・セル・文字起こし）と単語帳は、ブラウザの大きな保存領域（IndexedDB）に自動保存されます
  同じファイルを開き直すと復元されます（ファイル名を変えても、中身が同じなら復元されます）
  以前の版で localStorage に保存したメモは、最初の起動で自動的に移されます。使っている量は「設定」で見られます
- 保存データはブラウザとアドレスごとに分かれます。手元の `start.bat` 版と Web 版のメモは別々で、アドレスが変わると見えなくなります
  大事なメモは「書き出し」で JSON に保存してください。「読み込み」で、いま開いているメディアに追加できます
- 外部のサービスとやり取りするのは、YouTube の動画を開いたときと音声認識を使っているときだけです。詳しくは [privacy.html](privacy.html)

## 自分で公開する（GitHub Pages）

静的なファイルを置くだけで公開できます。利用者が増えてもサーバーの処理は増えません。

1. GitHub でリポジトリを作り、このフォルダの中身を push します
2. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして保存します
3. 数分で `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けるようになります

Cloudflare Pages や Netlify でも、ビルドなし・このフォルダをそのまま公開する設定で動きます。

注意:

- **公開するアドレスは最初に決めてください。** 利用者のメモはアドレス（ドメイン）ごとに保存されるため、あとで変えると見えなくなります
- アプリのファイルを足したときは、`sw.js` の `APP_FILES` にも足してください（オフラインで起動するため）
- 画面の文を足したり変えたりしたときは、英語の辞書 `js/i18n-en.js` にも同じ日本語をキーにして英語を足してください（辞書にない文は日本語のまま表示されます）
- YouTube の動画では、YouTube の規約に合わせて字幕をプレーヤーの上に重ねず、すぐ下の帯に出しています

## ファイル構成

- `index.html` / `css/` / `js/` … アプリ本体（`js/main.js` から読み込む ES モジュール）
- `js/broadcast.js` … YouTube のライブ配信（最新の場面へ戻る・ライブ中の記録をアーカイブに合わせる）
- `js/share.js` … 共有リンク（メモをリンクに詰める・開いたリンクを「〇〇さんの共有」として読み込む）
- `js/i18n.js` / `js/i18n-en.js` … 表示の言語の切り替えと、英語の辞書（日本語の文をキーにしている）
- `privacy.html` … プライバシーとデータの扱い
- `manifest.webmanifest` / `sw.js` / `icons/` … アプリとしてインストール・オフライン起動のため
- `serve.py` / `start.bat` … 手元の PC で動かすための小さな Web サーバー
