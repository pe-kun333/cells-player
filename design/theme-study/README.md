# 配色の検討（試作）

区間セルプレイヤーの色味を、ダーク以外（ホワイトなど）にも広げる検討のメモとモックです。
**アプリ本体のファイルは変えていません。** ここにあるものは、本体の画面に色を差し込んで見るためだけのものです。

- `lab.html` … 配色ラボ。いつものアプリを中に開いたまま、配色・アクセントの色・アンビエントを切り替えて試せます
- `themes.css` … 配色の案（本体の `:root` の色の変数を、テーマごとに上書きするだけ）
- `mock.css` … ラボが本体に差し込むモックの部品（設定の「配色」・セルの色の「色のセット」）
- `shots/` … 同じメモ（セル13・目印20・コメント・色付きのセル・2つの字幕）を入れた画面を、配色ごとに撮ったもの

## 試し方

1. `start.bat`（または `python -m http.server 8765`）で起動します
2. Chrome で `http://127.0.0.1:8765/design/theme-study/lab.html` を開きます
3. 上の帯で配色を選びます。中のアプリはいつもどおり使えて、メモもいつもと同じです（同じアドレスなので）
   - 「設定の『配色』を見る」で、設定の先頭に入れた「配色」のモックが見られます（ここからも切り替えられます）
   - セルの 🎨 のポップアップには「色のセット」のモックが出ます。これだけは登録した6色を実際に入れ替えます（「標準」で戻せます）

GitHub Pages に置けば、`…/cells-player/design/theme-study/lab.html` で、ふだんのメモのまま試せます。

## わかったこと（いまの配色）

- **ライトの配色はすでにあります。** ただ、OS の設定（ライト／ダーク）に合わせて自動で変わるだけで、アプリの中では選べません。
  OS をダークにしている人は、ライトの画面を見る方法がありません（逆も同じ）
- 色はほとんどすべて `:root` の変数（`--bg` `--panel` `--text` `--accent` など 27 個）で書かれています。
  そのため **テーマを足すのは、変数を上書きするだけで済みます**（`themes.css` だけで 10 種類を作り、レイアウトは一切さわっていません）
- 変数になっていない色が少しあります。テーマを足すなら、先に変数にしておくと楽です
  - アクセントの上の文字 `color: #fff`（11 か所。主ボタン・「再生中」の印・分割やドラッグの時刻の印など）→ `--on-accent`
  - 動画の枠と字幕の帯の黒（`.stage` `.caption-bar`）、字幕の背景 `rgba(0,0,0,.62)`、2つめの字幕の色 `#ffe7a3`
  - ドロップしたときの青 `rgba(43,108,212,.15)`、ダイアログの後ろの影、タブの影、YouTube の印の赤
  - `index.html` の `theme-color` と `manifest.webmanifest` の `theme_color`、ライブチャットの `dark_theme=1`（`js/broadcast.js` が OS の設定で決めている）
- コントラスト（WCAG の比）を測ると、いまの配色に2つ気になる所がありました

| 組み合わせ | いまのライト | いまのダーク | 目安 |
|---|---|---|---|
| 薄い文字 `--text-3` / パネル | **3.45** | 4.09 | 小さい文字は 4.5 以上 |
| 主ボタンの白い文字 / `--accent` | 5.00 | **2.61** | 4.5 以上 |
| ふつうの文字 `--text` / パネル | 16.88 | 13.22 | 4.5 以上 |

ダークの「このセルに」「分割」などの主ボタンは、白い文字が水色の上に乗っていて読みにくくなっています（`--on-accent` を暗い色にすると 7 以上になります）。
新しい案は、すべて薄い文字 4.5 以上・主ボタンの文字 4.5 以上になるように色を決めています。

### 決めるときに考えたこと

- **動画の枠は、白い配色でも黒のままにしました。** 映像の暗い所の見え方の基準になるためです（YouTube のライトの画面も同じ）。
  白い画面で動画の黒が浮いて見えるのが気になる人には「シアター」（帯ごと暗く）と「アンビエント」（下）を用意しました
- **いいね（ピンク）とアクセントの色がぶつからないように。** サクラはアクセントを梅紫にしたので、いいねを紅にずらしています。
  ペーパーは藍のアクセントに合わせて、いいねを朱にしました
- **白は文字を読むのに向いている一方、夜はまぶしい。** 明るい背景に暗い文字の方が読み取りの成績がよいという研究があります（瞳が小さくなってピントが合いやすいため、という説明）。
  学習用には白系が向きますが、夜や暗い部屋ではまぶしいので、「うす曇り」と「時間帯で切り替える」を合わせて考えました
- **セルの6色は配色と関係なく同じ色です。** 白・紙・紺のどれでも枠として見えるかを確かめました。
  色の見分けにくさに配慮した「色のセット」も試作しています（下）
- 各テーマで `color-scheme` も切り替えるので、選択肢・スクロールバー・音量のつまみなどのブラウザの部品も、その配色に合います

## モック

- 設定の「配色」（`shots/mock-settings-paper.webp` `mock-settings-crop.webp`）
  - 小さなアプリの絵で配色を選ぶ。「OSに合わせる」が最初の値（いまと同じ動き）
  - 時間帯で切り替える（昼: ホワイト／夜: ダーク、日の入りか決めた時刻で）
  - アクセントの色（6色＋テーマの色）。アクセントの仲間の色（薄い背景・文字の色・再生した範囲）は `color-mix()` で自動で作るので、1色選ぶだけで済みます（`mock-accent-mint-plum.webp`）
- アンビエント（`mock-ambient-white.webp` `mock-ambient-theater.webp`）
  - 動画を 30×17 の大きさに描いて、左右の3分の1ずつの色（鮮やかな所を重く）を、動画の黒い余白と下ににじませます
  - YouTube の「アンビエントモード」はダークの画面だけですが、こちらは白い画面でも余白の中に出るので浮きません
  - 手元のファイル・URL の動画だけです。YouTube はプレーヤーの中の絵を読めないので、サムネイルの色を使う案になります（画像を読めるかは要確認）
- セルの色の「色のセット」（`mock-cellsets-crop.webp`）
  - 標準 / 色覚に配慮（Okabe–Ito の配色）/ パステル / 和色（紅・柑子・山吹・若竹・藍・江戸紫）
  - いまの「色を登録」の画面を通して6色をまとめて入れ替えるだけなので、セルに持たせている番号はそのまま使えます

## 本体に入れるときの手順の案

1. 設定に `theme`（`'auto' | 'light' | 'dark' | 'white' | …`、最初は `'auto'`）を足す。設定の画面の先頭に「配色」、Ctrl+K に「配色: ホワイト」などを足す
2. `index.html` の `<head>` に小さなスクリプトを置き、CSS より前に `localStorage` の設定を読んで `<html data-theme>` を付ける（開いた瞬間に白→黒とちらつかないように）
3. `style.css` の `@media (prefers-color-scheme: dark)` を `:root:not([data-theme])` に限り、`[data-theme="dark"]` と新しいテーマのブロックを足す
   （または、色を `light-dark(明, 暗)` で書いて `color-scheme` だけ切り替える。Chrome 123 から使えます）
4. 上の「変数になっていない色」を変数にする（とくに `--on-accent`）
5. 配色が変わったら `<meta name="theme-color">` を書きかえ、ライブチャットの `dark_theme` も実際の配色で決める
6. 英語の辞書 `js/i18n-en.js` に、足した文の英語を足す（`sw.js` は、色を `style.css` の中に入れるならそのままでよい）
7. `prefers-contrast: more` のときは、最初の案内で「ハイコントラスト」をすすめる

## ほかの機能のアイデア

配色の検討から広げて考えたものです。手間は「小＝1日以内・中＝数日・大＝それ以上」のおおよそです。

### 見た目

| アイデア | うれしいこと | 手間 |
|---|---|---|
| 配色を選べる（上の案）＋ Ctrl+K で切り替え | OS がダークでも白で使える。用途で使い分け | 小 |
| 時間帯で自動切り替え | 昼は白、夜は暗く。手で変えなくてよい | 小 |
| アクセントの色を選ぶ | 1色選ぶだけで全体の印象を変えられる | 小 |
| 字幕の見た目（大きさ・背景の濃さ・縁取り・2つめの字幕の色） | 動画によって読みやすい字幕にできる。いまは 2つめの色が固定 | 小〜中 |
| 文字の大きさ・すき間（コンパクト／標準／ゆったり） | ノート PC の小さい画面でも、大きな画面でも使いやすい | 中 |
| ハイコントラストの自動提案・Windows のハイコントラスト（`forced-colors`）対応 | 見えにくい人も使える | 小 |
| セルの色に番号・模様も出す（タイムラインのバーにも） | 色だけに頼らずに見分けられる（配色の設計でも勧められていること） | 小 |
| 動画ごとの色（教材ごとにアクセントを決める） | ライブラリやプレイリストで、どの教材か一目でわかる | 中 |
| 印刷用の白い紙面（学習ノート） | セル・メモ・字幕を紙や PDF にまとめて復習できる。白い配色の延長 | 中 |

### 学習

| アイデア | うれしいこと | 手間 |
|---|---|---|
| 今日の復習（いいね・タグ付きのセルを 1日後・3日後・7日後…に出す） | 覚えたいところを忘れる前に聞き直せる。連続再生をそのまま使える | 中〜大 |
| シャドーイングで自分の声を録って聞き比べ | 発音の違いに自分で気づける（ブラウザの録音の機能で、外に送らない） | 中 |
| 学習の記録（日ごとの再生時間・練習回数のカレンダー） | 続けている実感。ライブラリの上に出す | 中 |
| 読むモード（字幕・文字起こしを大きく、いまの行を強調） | 本のように読みながら聞ける。ペーパーと相性がよい | 中 |

### 操作

| アイデア | うれしいこと | 手間 |
|---|---|---|
| イヤホン・キーボードのメディアキーで目印（Media Session） | 画面を見ずに、イヤホンのボタンで「目印」「少し戻る」 | 小 |
| フットペダル・ゲームパッド（Gamepad） | 書き起こしの定番の操作。両手で書きながら止める・戻す | 中 |
| いまのカードを浮かせる（Document Picture-in-Picture） | 別のアプリでノートを取りながら、手前の小さな窓で目印・コメント | 中 |

### データ・共有

| アイデア | うれしいこと | 手間 |
|---|---|---|
| 共有リンクを QR コードで出す | スマホでそのまま開ける | 小 |
| 決めたフォルダに自動で書き出す（File System Access） | Dropbox・OneDrive のフォルダに置けば、ほかの PC でも使える。サーバー不要のまま | 中 |
| 貼り付けた目次（YouTube の概要欄の 0:00 …）からセルを作る | チャプターをそのままセルにできる | 小 |

すすめる順: 配色を選べる → セルの色のセット・番号の表示・ハイコントラスト → メディアキーで目印 → 字幕の見た目 → 今日の復習
